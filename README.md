Diseño y desarrollo aplicaciones a partir de cómo trabaja cada persona o empresa, no al revés. Escucho el problema, encuentro la solución y la convierto en un producto claro, fiable y listo para el día a día, sea cual sea el sector.

Me muevo entre la oficina y la planta: aplicaciones web de gestión, herramientas internas y automatización industrial.

### Qué hago

- **Aplicaciones de gestión a medida** — operativa, equipos, proyectos, facturación.
- **Herramientas internas** que sustituyen hojas de cálculo, papel y mensajes sueltos.
- **Automatización industrial** — PLC, HMI/SCADA e integración de datos de planta.
